# User Documentation

[English](README.md) · [简体中文](README.zh-CN.md)

## Overview

Every user guide in this directory has English and Simplified Chinese editions. The README introduces the theme and provides quick installation. Configuration details, writing, and troubleshooting each have a directly linked document. Explanations and default values share one configuration document. This module inventory is excluded from the installation archive.

## Main Interfaces / Implementations

| File | Kind | Description |
| --- | --- | --- |
| configuration.md / configuration.zh-CN.md | User guide | Configuration behavior, examples, presets, and generated default values. |
| content.md / content.zh-CN.md | User guide | Posts, About, custom pages, and optional integrations. |
| usage.md / usage.zh-CN.md | User guide | Theme-directory `npm install`, archive installation, upgrades, rollback, and troubleshooting. |
| license.md / license.zh-CN.md | License guide | English MIT text and a Chinese reference translation; the original LICENSE is unchanged. |
| theme.schema.json | Editor schema | Completion and validation for a blog's theme overrides. |
| images/ | Illustrations | Screenshots used in the user guides. |

Contributor operations are documented in [CONTRIBUTING.md](../CONTRIBUTING.md). English files have no language suffix and are the default; Chinese files use `.zh-CN.md`.
