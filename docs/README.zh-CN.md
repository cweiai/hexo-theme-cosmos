# 用户文档

[English](README.md) · [简体中文](README.zh-CN.md)

## 概览

本目录所有用户指南均有英文和简体中文版本。README 介绍主题并提供快速安装；配置详情、写作、使用与排错各有直接链接的独立文档。配置说明与默认值位于同一篇文档。本模块清单不进入安装包。

## 主要接口与实现

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| configuration.md / configuration.zh-CN.md | 用户指南 | 配置行为、示例、预设及自动生成的默认值。 |
| content.md / content.zh-CN.md | 用户指南 | 文章、About、自定义页面和可选接入。 |
| usage.md / usage.zh-CN.md | 用户指南 | 主题目录内的 `npm install`、发行包安装、升级、回滚和排错。 |
| license.md / license.zh-CN.md | 许可证说明 | 英文 MIT 文本和中文参考译文；原始 LICENSE 保持不变。 |
| theme.schema.json | 编辑器 Schema | 对博客主题配置进行补全和验证。 |
| images/ | 图片 | 用户指南中的真实截图。 |

贡献者操作见[贡献指南](../CONTRIBUTING.zh-CN.md)。英文文件不带语言后缀，是默认版本；中文文件使用 `.zh-CN.md`。
