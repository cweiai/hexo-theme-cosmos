# Configuration Presets

[English](README.md) · [简体中文](README.zh-CN.md)

## Overview

Optional configuration recipes using existing Cosmos settings. Merge a preset into a real blog's `_config.cosmos.yml`; preserve its identity and personal content.

## Main Interfaces / Implementations

| Name | Kind | Description |
| --- | --- | --- |
| minimal-cover.yml | Cover recipe | Static full-screen cover, compact footer/navigation, and editorial reading details. |
| writing.yml | Writing recipe | Blog at the root, narrow reading width, updated dates, and numbered contents. |
| portfolio.yml | Portfolio recipe | Projects entrance, custom Projects content, and full-width About body. |

See [configuration recipes](../docs/configuration.md#ready-to-use-configurations). Arrays replace defaults, so inspect navigation and custom page lists before merging.
