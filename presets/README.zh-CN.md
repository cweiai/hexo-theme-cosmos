# 配置预设

[English](README.md) · [简体中文](README.zh-CN.md)

## 概览

使用现有 Cosmos 设置的可选方案。将预设合并到真实博客的 `_config.cosmos.yml`，保留个人信息和内容。

## 主要接口与实现

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| minimal-cover.yml | 封面方案 | 静态全屏封面、精简页脚和导航，以及阅读细节。 |
| writing.yml | 写作方案 | 首页文章列表、较窄阅读宽度、更新日期和带编号目录。 |
| portfolio.yml | 作品集方案 | 项目入口、自定义 Projects 内容和通栏 About 正文。 |

参见[配置方案](../docs/configuration.zh-CN.md#现成配置方案)。列表会替换默认值，合并前检查导航和自定义页面列表。
