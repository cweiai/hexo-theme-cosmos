## 概览

静态公开资源，不含个人内容或运行时远端依赖。

代码标记行的底色和 2px 强调色竖线向已有左侧内边距延伸 10px，并以等量行内边距保持代码对齐，使竖线与代码之间留出 8px 间隔；手机宽度下也保持此效果。

两种语言的模块说明都不会进入安装包或生成的博客资源；站点自己编写的 README 页面仍可正常发布。

代码框采用一致的上下内边距。启用复制时，`main.js` 将复制按钮放在可通过键盘聚焦的滚动区域旁，并与第一行代码对齐。Highlight.js 与 Prism 风格的 `pre` 代码框使用相同布局，标题横跨两列。长行可横向滚动，不会移动或遮挡按钮。关闭 JavaScript 或禁用复制时，代码使用完整宽度；打印时移除按钮列。

动效延续 `style.css` 的缓动变量，包括首访封面入场、跨页移动的指示标记、目录下划线与锚点高亮、可反向收起的移动导航、原生折叠过渡和方向一致的指针反馈。`main.js` 保留仍匹配的搜索条目并过渡其位置，复制时提供滚动文案、勾选和蜂蜜色扫光。重复操作会从当前状态继续或取消旧动效。键盘触发菜单和复制时立即切换；关闭的移动导航链接处于 inert 状态。`motion.enabled: false` 关闭主题添加的所有动态效果，`motion.page_transitions: false` 仅关闭跨页面切换。所有效果遵循系统的减少动态效果偏好，不支持相关 CSS 时回退到原生行为。封面访问记录按标签页和站点根路径区分。

## 主要接口与实现

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| css/style.css | 样式表 | 页面布局、排版、响应式图库、代码行标记、CSS 变量和响应式状态。 |
| js/main.js | 浏览器脚本 | 本地化导航、搜索条目复用、阅读进度、复制反馈和封面访问记录。 |
| js/transitions.js | 浏览器脚本 | 渐进增强的文章标题页面切换。 |
| fonts/ | 资源 | 本地字体及其许可证。 |
