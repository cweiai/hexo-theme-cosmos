## 概览

静态公开资源，不含个人内容或运行时远端依赖。

两种语言的模块说明都不会进入安装包或生成的博客资源；站点自己编写的 README 页面仍可正常发布。

代码框采用一致的上下内边距。启用复制时，`main.js` 将复制按钮放在可通过键盘聚焦的滚动区域旁，并与第一行代码对齐。Highlight.js 与 Prism 风格的 `pre` 代码框使用相同布局，标题横跨两列。长行可横向滚动，不会移动或遮挡按钮。关闭 JavaScript 或禁用复制时，代码使用完整宽度；打印时移除按钮列。

## 主要接口与实现

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| css/style.css | 样式表 | 页面布局、排版、响应式图库、代码行标记、CSS 变量和响应式状态。 |
| js/main.js | 浏览器脚本 | 本地化导航、搜索、阅读进度和代码复制。 |
| js/transitions.js | 浏览器脚本 | 渐进增强的文章标题页面切换。 |
| fonts/ | 资源 | 本地字体及其许可证。 |
